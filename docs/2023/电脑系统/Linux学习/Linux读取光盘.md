# Linux读取光盘

> 2026-09-25 19:19:39

一般的光盘（比如DVD）可以在文件系统中直接打开，直接读取里面的文件就行。

部分光盘（比如VCD、蓝光盘）无法直接播放，就需要**下载vcl播放器**

***前置条件：去应用市场下载VCL播放器***

## vcl播放光盘

* 一般来说，插入光盘后，vcl播放器会自动启动
* 但建议先去文件系统里面看能不能访问光盘里面的文件（确认是否DVD)，不能再使用vcl播放器

**打开VLC之后播放光碟**

1. 顶部菜单 媒体(Media) → 打开光碟(Open Disc) 
2. 选`SVCD/VCD`
3. 光碟设备默认`/dev/sr0`，直接点播放

## vcl导出VCD中视频

> VLC直接转码保存视频（图形界面，不用敲长命令）

1. 打开VLC → 媒体 → 转换/保存（快捷键  Ctrl+R ）
2. 切换到「光碟」标签，选择`SVCD/VCD`，设备填`/dev/sr0 `（默认）
3. 点右下角「转换/保存」
4. 配置文件：Video - H.264 + MP3 (MP4) 
5. 目标文件：选一个保存位置，命名输出mp4
6. 点开始，直接把VCD视频抓成mp4存硬盘。
